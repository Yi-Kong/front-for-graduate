# 侧边栏「退出登录」设计稿（sidebar-logout）

> 日期：2026-10-05 · 状态：**待批准**（批准后才落地 `src/` 代码）

## 1. 现状问题

`src/components/AppSidebar.vue` 底部用户区（129-144 行）目前已有退出入口，但它是：

- 一个 **30×30 的纯图标小方钮**，没有任何文字提示（只有 `title="退出登录"`）；
- 点击后**直接退出**，无二次确认，误触即丢登录态；
- 视觉上与头像/姓名挤在一行，存在感弱，符合不了「左下角明确退出功能」的预期。

## 2. 方案对比

### 方案 A（推荐）：底部用户区显式「退出登录」文字按钮

保持现有布局（头像 + 姓名/角色），把右侧小方钮升级为**图标 + 文字的按钮**：

```
┌──────────────────────────────────┐
│ (管)  王管理员            ┌────────────┐ │
│       管理员 · ADMIN      │ ⎋ 退出登录 │ │
│                          └────────────┘ │
└──────────────────────────────────┘
```

- **尺寸**：高 34px，圆角 10px，内边距 0 10px，图标 15px + 文字 12.5px；
- **默认态**：底色 `#f3f4f6`、文字/图标 `#6b7280`；
- **hover**：底色 `#fdecee`、文字/图标 `#C0202E`（与现有菜单 hover 语言一致）；
- **active**：`translate-y-px`（全站按钮微下沉惯例）；
- 宽度自适应，空间不足时姓名区 `truncate` 已有兜底。

### 方案 B：头像点击弹出 Popover 菜单（内含「退出登录」项）

- 头像/整行可点，弹出小菜单：`个人身份信息`（只读展示）+ 分隔线 + `退出登录`（红字）；
- 需要新增 Popover 交互与焦点管理，复杂度更高；
- 当前系统**无个人中心页**，菜单里没有其他可去的地方，收益低。

**结论：选 A**。改动最小、入口最显眼，交互路径短。

## 3. 交互流程（方案 A）

1. 点击「退出登录」按钮 → 弹出**确认框**（复用公共 `ConfirmDialog` 组件）：
   - 标题：`退出登录`
   - 正文：`确定要退出当前账号吗？退出后需重新登录。`
   - 确认按钮：`退出`（danger 红色）；取消按钮：`取消`；
2. 确认后执行 `auth.logout()`（清 token/user/localStorage）→ `router.replace('/login')`；
3. 移动端（`<md`）抽屉侧边栏内同样生效，点击后先关抽屉再跳转。

> 为什么加确认：当前 `onLogout()` 是立即退出，误触代价高（表单未保存内容全丢）；确认框成本极低且与全站 `ConfirmDialog` 交互一致。

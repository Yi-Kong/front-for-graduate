选题轮次管理

配置本届毕业设计的选题轮次（如第一轮、第二轮）。轮次开启后，学生可在开放时间内选题意向；轮次关闭后系统自动依据选题结果生成师生指导关系。

设计稿说明：轮次状态分「待开始 / 进行中 / 已结束」三态，行内操作随状态变化；「关闭」将触发生成指导关系，故需二次确认；指导情况统计区当前后端接口未就绪，先以空态占位。

后端契约要点：① 列表 GET /api/selection-rounds/，字段为 id / academic_year / round_no / start_time / end_time / status（无 is_first 字段，规划中的「是否首轮」不在契约内）；② 新增仅提交 academic_year / round_no / start_time / end_time，id 与 status 由系统生成（初态 PENDING）；③ open/ 与 close/ 仅传路径 id、无请求体，close/ 响应返回 assignments_created；④ 统计区依赖的 supervision_statistics 接口缺失，本期以空态呈现，待后端补齐。

新增轮次

默认取当前届次；轮次按所选学年独立编号。
同一学年内从 1 递增，系统已按已有轮次预填建议值。
截止时间须晚于开放时间；开启后学生方可在此窗口内选题。

关闭选题轮次

确认关闭「第一轮」？关闭后系统将依据本轮学生选题结果自动生成师生指导关系，且轮次不可再开启。
预计生成指导关系：≈ 128 条（以实际提交为准，响应返回 assignments_created）
